In this chapter, you'll create your first page component and use it to render the site.

== Page components

So far, the content has no visual presentation. In the Site Framework, a _page component_ is what turns a content item into a web page. It consists of three files, placed together in a folder under `src/main/resources/cms/pages/`:

* A _descriptor_ (`.yaml`), which makes the page component available in Content Studio
* An _implementation_ (`.ts`), which handles the request and returns a response
* A _view_ (`.html`), a template the implementation uses to produce the markup

When a visitor requests a content item, the site service finds the page component selected for it, and runs its implementation. The implementation exports a function per HTTP method it supports, such as `GET`.

== Libraries

Apps get their functionality from libraries, which are added to the build file. The page component uses two of them: the Portal library, which gives access to the content being rendered, and the Thymeleaf library, which renders HTML templates.

=== Task: Add the libraries

. *Include the libraries* - In `build.gradle`, both libraries are listed, but commented out. Remove the `//` in front of these two lines:
+
.build.gradle
[source,groovy]
----
  include xplibs.portal
----
+
[source,groovy]
----
  include libs.thymeleaf
----

. *Install the type definitions* - The Portal library types are already installed. Stop `enonic dev` with kbd:[Ctrl+C], and install the ones for Thymeleaf:
+
[source,shell]
----
npm install --save-dev @enonic-types/lib-thymeleaf
----

. *Map the import path* - In `src/main/resources/tsconfig.json`, add this line to `compilerOptions.paths`, above the `"/lib/xp/*"` entry:
+
.src/main/resources/tsconfig.json
[source,json]
----
      "/lib/thymeleaf": ["../../../node_modules/@enonic-types/lib-thymeleaf"],
----

. *Restart dev mode* - Changes to `build.gradle` are only picked up when the build starts. Run `enonic dev` again, and wait for `BUILD SUCCESSFUL`.

=== Task: Add the page to the site

. *Open the site* - In Content Studio, select `Hello World` and click btn:[Edit].

. *Open the page settings* - Click the btn:[Show Context Panel] icon in the top right corner. In the dropdown at the top of the panel, select `Page`.

. *Select the page component* - In the `Template` field, select `Hello page`:
+
image::page-settings.png["The context panel with the Template dropdown open, listing Automatic and Hello page", width=1440]

. *Verify the result* - The preview panel now shows the site, rendered by your page component. Content Studio saves the page setup automatically:
+
image::hello-page.png["The preview panel showing the heading Hello World - we made it!", width=1440]

TIP: Click btn:[Preview] in the toolbar to open the page in a separate browser tab.
