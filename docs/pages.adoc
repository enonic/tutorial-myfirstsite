In this chapter, you'll get to know the page component that ships with your app - its descriptor, controller, and view - and use it to render the site.

== Page component

At this point, you have content, but nothing renders it. With the {xp-docs}/{xp-docs-version}/framework[Enonic Site Framework], XP renders the content itself.
A page is composed of one or more components, always with a page component as its root.

Your app includes a page component named `hello`. A component is defined by a descriptor file, placed in a particular location within your app. For page components, that is `src/main/resources/site/pages/`:

.src/main/resources/site/pages/hello/hello.xml
[source,xml]
----
include::{sourcedir}/hello/hello.xml[]
----

TIP: Like content types, components can define a form using the {xp-docs}/{xp-docs-version}/cms/schemas[schema system]. You'll see an example in the <<parts#,parts chapter>>.

== Controller

Each component can have its own controller, which is responsible for rendering it. This is the controller of the `hello` page component:

.src/main/resources/site/pages/hello/hello.ts
[source,typescript]
----
include::{sourcedir}/hello/hello.ts[]
----

NOTE: The controller file must be placed in the component directory and use the same name as the directory.

The controller is written in TypeScript. The build system compiles each `.ts` file and places the generated `.js` file in the same location. XP picks up and invokes the resulting `.js` file.

== View

The controller passes its model to an HTML template - the view in the Model View Controller (MVC) pattern:

.src/main/resources/site/pages/hello/hello.html
[source,html]
----
include::{sourcedir}/hello/hello.html[]
----

The view is plain HTML, extended with attributes from the https://market.enonic.com/vendors/enonic/thymeleaf-lib[Thymeleaf] templating language.
Other template engines are available as libraries, such as https://market.enonic.com/vendors/enonic/mustache-lib[Mustache] and https://market.enonic.com/vendors/tineikt/freemarker-xp-library[Freemarker].

== Task: Create your first page

For the `hello` page component to render something, a content item must use it.

. *Open the site* - In Content Studio, select the `Hello World` site and click btn:[Edit].

. *Select the page component* - In the preview panel on the right-hand side, select `Hello Page Controller` in the list.
Your changes are saved automatically.

. *Verify the rendering* - The preview shows the display name of the site, followed by the text `- we made it!`:
+
image::hello-world.gif["Setting up the page", width=960]

== Summary

You've seen how a page component consists of a descriptor, a controller, and a view, and used it to render the `Hello World` site.
The page isn't entirely static: the controller reads the display name of the content and passes it to the view, which adds a hardcoded text.

TIP: To learn more about pages, visit the {xp-docs}/{xp-docs-version}/cms/pages[pages documentation].
