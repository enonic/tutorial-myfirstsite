In this chapter, you'll add a region to the page component, so editors can compose the page from other components.

== Regions

A _region_ is a named area of a page where editors can place components. The page component declares its regions in the descriptor, and decides in its view where each region ends up in the markup.

The components themselves are not rendered by the page. For each component in a region, the view leaves a placeholder, and the site service replaces it with the rendered component.

The `data-portal-region` attribute tells Content Studio where the region is. Inside it, the view loops over the components of the region, and outputs a placeholder for each of them with `data-portal-component`.

. *Verify the result* - In Content Studio, open the `Hello World` site and select the `Page` tab above the form. The tab lists the components of the page as a tree, with the `main` region below the page component. The preview shows the empty region as a drop zone:
