In this chapter, you'll add a region to the page component, so pages can be composed from several components in Content Studio.

== Component dropzones

A region is a named area of a page where editors can add components. For Content Studio to offer this, the page component must declare one or more regions.

=== Task: Add a region to the page

Add a single region called `main` to the `hello` page component, using the code samples that came with the starter.

. *Update the descriptor* - Replace the content of the page component descriptor with the following, which declares the region:
+
.src/main/resources/site/pages/hello/hello.xml
[source,xml]
----
include::{sourcedir}code-samples/pages/hello-region/hello.xml[]
----

. *Update the controller* - Replace the content of the controller with this version, which passes the region to the view:
+
.src/main/resources/site/pages/hello/hello.ts
[source,typescript]
----
include::{sourcedir}code-samples/pages/hello-region/hello.ts[]
----

. *Update the view* - Replace the content of the view with this version, which renders the region:
+
.src/main/resources/site/pages/hello/hello.html
[source,html]
----
include::{sourcedir}code-samples/pages/hello-region/hello.html[]
----
+
Your sandbox picks up the changes automatically, since `enonic dev` is running.

. *Open a country* - In Content Studio, select one of the country content items and click btn:[Edit].

. *Select the page component* - Activate the page editor with the monitor icon in the top right corner, and select the `Hello Regions!` page component.

. *Verify the region* - The page now contains an empty region, marked `Drop here`:
+
image::hello-regions.gif["Setting up a page with a region", width=960]

== Text component

The Text component is a standard component included in XP. It comes with a default rendering, which you can customize if needed.

=== Task: Add text to the region

. *Insert a text component* - Drag `Text` from the `Components` widget on the right-hand side into the region.
You can also right-click the region and select `Insert` -> `Text`.

. *Write some text* - Type a text, for example "Hello Regions!", and save the content.

. *Verify the result* - The text is rendered inside the region, below the page heading.

For more details, visit the reference documentation for the {xp-docs}/{xp-docs-version}/cms/pages/text[Text component].

== Summary

You've declared a region in the page component, and filled it with a text component from Content Studio.
Regions aren't limited to pages. They are also used in layouts, a component type you'll meet in the <<layouts#,layouts chapter>>.

TIP: To learn more about regions, visit the {xp-docs}/{xp-docs-version}/cms/pages/regions[regions documentation].

Next, you'll <<parts#,add parts to the region>>. Parts are components you write the rendering for yourself.
