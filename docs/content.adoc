== Content types

Every content item in Enonic has a _content type_. The content type defines the fields editors fill in, and therefore the data you have available when you render the content.

The site in this tutorial presents countries and their cities, so you need a content type for each. Content types are YAML files in the `src/main/resources/cms/content-types/` folder, each in a folder with the same name as the file.

=== Task: Create the content types

. *Create the country content type* - Create the file below with the following content:
+
.src/main/resources/cms/content-types/country/country.yaml
[source,yaml]
----
include::{sourcedir}/cms/content-types/country/country.yaml[]
----
+
A country has a description and a link to Wikipedia. The name of the country is the display name that every content item has, so it needs no field of its own.

. *Create the city content type* - Create the file below with the following content:
+
.src/main/resources/cms/content-types/city/city.yaml
[source,yaml]
----
include::{sourcedir}/cms/content-types/city/city.yaml[]
----
+
A city has a photo, a slogan, and a population. The `occurrences` setting makes the population mandatory.

. *Verify the build* - The terminal running `enonic dev` prints `BUILD SUCCESSFUL` again. Your app now contains the two content types.

TIP: To learn more about forms and input types, visit the {cms-docs}/content/content-types[content types documentation].

== Sample content

Instead of typing in a set of countries and cities yourself, you'll install a small app that does it for you. The `{fixture-app-title}` app creates a content project called `{cms-project-displayname}`, with a site, three countries, and their cities.

=== Task: Install the sample content

. *Download the app* - Download {fixture-url}[{fixture-file}] to your computer.

. *Upload the app* - Click btn:[Install]. In the dialog, click the upload button to the right of the search field, and select the file you downloaded:

image::install-fixture.png["The Install Application dialog with a search field and an upload button", width=1440]

== Content Studio

Content Studio is the editorial interface of Enonic. This is where editors create and publish content, and where you'll put together the pages of your site.

=== Task: Explore the content

. *Open Content Studio* - Go back to the XP admin home page and click btn:[Content Studio]. It opens in the `{cms-project-displayname}` project.

. *Expand the site* - Click the arrow to the left of the `Hello World` site to list the countries, and select one of them:
+
image::content-studio.png["Content Studio with the Hello World site expanded, showing Colombia, Norway, USA and Templates", width=1440]
+
The preview panel on the right says `No preview available`. The content exists, but nothing renders it yet.

. *Look at a country* - Select `Norway` and click btn:[Edit]. The form has the fields you defined in the `country` content type. Close the browser tab when you are done.

== Sites and apps

A _site_ is a content item that marks the root of a website. Apps are added to a site, and this makes the content types and components of the app available to the content below it.

The sample content already uses your content types. To create new content with them, and later to render pages, your app must be added to the site.

=== Task: Add your app to the site

. *Open the site* - Select `Hello World` and click btn:[Edit].

. *Add the app* - In the `Applications` field, search for `{app-title}`, select it, and click btn:[Apply]:
+
image::site-app.png["The Hello World site with the Site Framework tutorial app added in the Applications field", width=1440]
+
Content Studio saves the change automatically.

. *Close the tab* - Go back to the browser tab with the content list.

=== Task: Create a country and a city

. *Create a country* - Select `Hello World` and click btn:[New]. Select `Country` in the dialog:
+
image::new-content.png["The dialog for creating content, listing the available content types", width=1440]

. *Fill in the form* - Use `Sweden` as the display name, add a description and a Wikipedia URL, and click btn:[Save]:
+
image::new-country.png["The form for a new country, with display name, description and Wikipedia URL filled in", width=1440]

. *Create a city* - Go back to the content list, select `Sweden`, and click btn:[New]. Select `City`, and use `Stockholm` as the display name. Fill in a slogan and a population, and click btn:[Save]:
+
image::new-city.png["The form for a new city, with display name, slogan and population filled in", width=1440]

. *Verify the result* - In the content list, `Sweden` is listed below `Hello World`, with `Stockholm` below it.

== Summary

You've created two content types, installed sample content, added your app to the site, and created content of your own.
Content types, sites, and the content itself are part of the CMS, and work the same way whichever front-end you use.
