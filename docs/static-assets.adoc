In this chapter, you'll style the site by serving a CSS file with the Asset library.

== Asset library

So far, the site consists of HTML and images from the content. Static assets, such as CSS and JavaScript files, are served by the https://developer.enonic.com/docs/lib-asset[Asset library]. Every file you place in the `src/main/resources/assets/` folder gets a URL, which you create with the `assetUrl()` function.

=== Task: Add the Asset library

. *Include the library* - In `build.gradle`, remove the `//` in front of this line:
+
.build.gradle
[source,groovy]
----
  include libs.asset
----

. *Install the type definitions* - Stop `enonic dev` with kbd:[Ctrl+C], and run:
+
[source,shell]
----
npm install --save-dev @enonic-types/lib-asset
----

. *Map the import path* - In `src/main/resources/tsconfig.json`, add this line to `compilerOptions.paths`, above the `"/lib/xp/*"` entry:
+
.src/main/resources/tsconfig.json
[source,json]
----
      "/lib/enonic/asset": ["../../../node_modules/@enonic-types/lib-asset"],
----

. *Expose the asset API* - The library serves the files through an API, which must be listed in the site descriptor. Replace the content of the site descriptor with the following:
+
.src/main/resources/cms/site.yaml
[source,yaml]
----
include::{sourcedir}/cms/site.yaml[]
----

=== Task: Serve a CSS file

. *Create the stylesheet* - Create the file below with the following content:
+
.src/main/resources/assets/styles/main.css
[source,css]
----
include::{sourcedir}/assets/styles/main.css[]
----

. *Update the implementation* - Replace the content of the page component implementation with the following:
+
.src/main/resources/cms/pages/hello/hello.ts
[source,typescript]
----
include::{sourcedir}/cms/pages/hello/hello.ts[]
----
+
The model now includes the URL of the stylesheet.

. *Update the view* - Replace the content of the page component view with the following:
+
.src/main/resources/cms/pages/hello/hello.html
[source,html]
----
include::{sourcedir}/cms/pages/hello/hello.html[]
----
+
One line has changed: a `<link>` element in the `<head>` includes the stylesheet.

. *Restart dev mode* - Run `enonic dev` again, and wait for `BUILD SUCCESSFUL`.

. *Verify the styling* - In Content Studio, select a country. The preview is now styled:
+
image::css.png["The preview of Norway with styling: a heading with a colored line below it, and each city in a bordered box", width=1440]

== Caching

The URL of the stylesheet looks something like this:

[source,text,{subs}]
----
/site/{cms-project-id}/draft/hello-world/_/{app-name-full}:asset/1795477566231/styles/main.css
----

The number is a fingerprint of the app, and changes every time the app is deployed. Because a new version of a file always gets a new URL, the Asset library can tell browsers and CDNs to cache each URL for as long as they like.

NOTE: In development mode, which you are using now, the caching is deactivated.
