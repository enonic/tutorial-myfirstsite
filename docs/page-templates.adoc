In this chapter, you'll turn the page you made for Norway into a page template, so every country gets the same page.

== Page templates

The page you composed belongs to Norway only. The other countries still have no page, and composing one for each of them would not scale.

A _page template_ is a content item that holds a page setup, and a list of the content types it supports. When a content item has no page of its own, the site service looks for a page template that supports its content type, and renders the item with that.

=== Task: Create a page template

. *Save the page as a template* - In the editor for `Norway`, select the `Page` tab. Right-click the page component, `Hello page`, at the top of the component tree, and select `Save as Template`:
+
image::save-as-template.png["The context menu of the page component, with Inspect, Reset and Save as Template", width=1440]

. *Rename the template* - The new page template opens in a separate browser tab. It supports the `Country` content type, and is named after the content it was created from. Change the display name to `Country`, and click btn:[Save]:
+
image::page-template.png["The page template named Country, supporting the Country content type", width=1440]
+
The preview shows `Missing description` and `No cities found`, because the template itself is not a country.

=== Task: Use the template for all countries

Norway still has its own page, which takes precedence over the template.

. *Reset the page* - Go back to the editor for `Norway`. Right-click `Hello page` in the component tree, select `Reset`, and confirm. Norway now gets its page from the template, and looks the same as before.

. *Verify the result* - Go back to the content list and select another country, for instance `Colombia`. The preview shows it with the same page:
+
image::template-applied.png["The preview of Colombia, rendered with the page template", width=1440]

Page templates are stored in the `Templates` folder below the site. To change the page for all countries, edit the template.

== Summary

You've created a page template from an existing page, and used it to render all content of the same type.
