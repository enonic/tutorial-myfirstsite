In this chapter, you'll create two parts: one that presents a country, and one that lists its cities and can be configured by editors.

== Parts

A _part_ is a component editors can place in a region. Like a page component, it consists of a descriptor, an implementation, and a view. Parts are placed in the `src/main/resources/cms/parts/` folder.

Parts are rendered in the context of the content item the page belongs to. This means the same part shows different content on different pages.

=== Task: Add the part to a country

. *Open a country* - In Content Studio, select `Norway` and click btn:[Edit].

. *Select the page component* - Open the context panel and select `Page` in its dropdown, as you did for the site. In the `Template` field, select `Hello page`. The preview shows the page with an empty region.

. *Insert a part* - Select the `Page` tab above the form. Right-click the `main` region in the component tree, and select menu:Insert[Part]:
+
image::part-insert.png["The context menu of the main region, with Insert and then Part selected", width=1440]

. *Select the part* - An empty part appears in the region, and the context panel shows a `Part` field. Select `Country`.

. *Verify the result* - The preview shows the description of Norway, and a link to Wikipedia:
+
image::country-part.png["The preview of Norway, showing its description and Wikipedia link below the heading", width=1440]

== City list part

The second part lists the cities of a country, which are the child items of the country content. It also has a form, which lets editors choose how the city photos are cropped.

=== Task: Create the city list part

. *Include the Content library* - The part uses the Content library to fetch the cities. In `build.gradle`, remove the `//` in front of this line:
+
.build.gradle
[source,groovy]
----
  include xplibs.content
----
+
Then stop `enonic dev` with kbd:[Ctrl+C], and run it again.

. *Create the descriptor* - Create the file below with the following content:
+
.src/main/resources/cms/parts/city-list/city-list.yaml
[source,yaml]
----

----
+
The `form` works like the form of a content type, but the values are stored with the component.

. *Create the implementation* - Create the file below with the following content:

----

----
+
`getComponent()` returns the part itself, including the values of its form in `config`. `getChildren()` fetches the child items of the country, and `imageUrl()` creates a URL to each photo, scaled as configured.

. *Create the view* - Create the file below with the following content:
+

=== Task: Add and configure the part

. *Insert the part* - In the editor for `Norway`, right-click the `main` region again, and select menu:Insert[Part]. Select `City list` in the `Part` field. The part is added below the country part.

. *Configure the part* - With the part selected, select `Widescreen` in the `Image crop` field in the context panel, and click btn:[Apply].

. *Verify the result* - The preview lists the cities of Norway, and the photo is cropped to a wide format:
+
image::city-list-part.png["The preview of Norway with the country part and a list of cities, and the Image crop setting in the context panel", width=1440]
