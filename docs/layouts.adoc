In this chapter, you'll use a layout to arrange components in two columns, and see how a component can contribute CSS to the page it is placed on.

== Two-column layout

Layouts are components that contain regions, which makes them containers for other components. Your app includes a layout with two regions that work as columns, and a configuration option that lets editors control the width of each column.

Like pages and parts, a layout consists of a descriptor, a controller, and a view. Layouts are placed in the `src/main/resources/site/layouts/` folder:

.src/main/resources/site/layouts/two-columns/two-columns.xml
[source,xml]
----
include::{sourcedir}/site/layouts/two-columns/two-columns.xml[]
----

The descriptor combines what you've seen in pages and parts: it declares regions, and it has a form.

.src/main/resources/site/layouts/two-columns/two-columns.ts
[source,typescript]
----
include::{sourcedir}/site/layouts/two-columns/two-columns.ts[]
----

.src/main/resources/site/layouts/two-columns/two-columns.html
[source,html]
----
include::{sourcedir}/site/layouts/two-columns/two-columns.html[]
----

== Page contributions

The layout comes with CSS that is only loaded on pages where the layout is used. The stylesheet is placed in the assets folder:

.src/main/resources/assets/styles/two-columns.scss
[source,scss]
----
include::{sourcedir}/assets/styles/two-columns.scss[]
----

NOTE: The build system compiles the `scss` file to `css`.

To add the CSS to the page, the controller uses {xp-docs}/{xp-docs-version}/framework/contributions[page contributions]. A page contribution lets a component inject HTML at specific places in the resulting markup: at the beginning or end of `<head>`, or at the beginning or end of `<body>`.

The controller above returns the page contribution together with the rest of its response.

== Task: Add the layout to a page

. *Open the site* - In Content Studio, select the `Hello World` site and click btn:[Edit].

. *Insert the layout* - Insert a layout in the `main` region, and select `Two columns` in the list:
+
image::two-column-layout.png["Two-column layout with the 50/50 setting and empty left and right regions", width=1226]

. *Add text to the columns* - Add a text component to each of the two regions, and write some text:
+
image::two-column-layout-with-texts.png["Two-column layout with the 50/50 setting and a text in each region", width=1226]

. *Change the column sizes* - With the layout selected, switch between `33/66`, `50/50`, and `66/33` in the `Column sizes` dropdown in the panel on the right-hand side.

. *Verify the result* - The width of the columns follows the setting you select:
+
image::two-column-layout-33-66-with-texts.png["Two-column layout with the 33/66 setting and a text in each region", width=1226]
