== Layouts

A _layout_ is a component with regions of its own, which makes it a container for other components. Like pages and parts, a layout consists of a descriptor, an implementation, and a view. Layouts are placed in the `src/main/resources/cms/layouts/` folder.

== Page contributions

The stylesheet of the layout is only needed on pages where the layout is used. The page component knows nothing about the layout, so the layout adds the stylesheet itself, with a {code-docs}/web/sites/contributions[page contribution].

A page contribution lets a component inject markup at specific places in the page: at the beginning or end of `<head>`, or at the beginning or end of `<body>`. The implementation above returns a `pageContributions` property in its response, with a `<link>` element for the end of `<head>`.

== Layout in the page template

=== Task: Add the layout to the page template

. *Open the page template* - In Content Studio, expand the `Templates` folder below the site, select the `Country` template, and click btn:[Edit].

. *Insert the layout* - Select the `Page` tab. Right-click the `main` region in the component tree, and select menu:Insert[Layout]. In the `Layout` field in the context panel, select `Two columns`.

. *Move the parts into the columns* - The layout appears in the component tree, with the regions `left` and `right` below it. Drag the `Country` part onto `left`, and the `City list` part onto `right`.

. *Save the template* - Click btn:[Save].

. *Change the column sizes* - Select `Two columns` in the component tree. In the context panel, select `33/66` in the `Column sizes` field, and click btn:[Apply]:
+
image::two-columns.png["The page template with the layout selected, the two parts in its left and right regions, and the Column sizes setting", width=1440]

. *Verify the result* - Go back to the content list and select a country. The description is shown in a narrow column on the left, and the cities in a wide column on the right.
