= Build a website with the Enonic Site Framework

Learn the basic principles of pages, components, and rendering with the Enonic Site Framework.

TIP: Enonic also support rendering with https://developer.enonic.com/docs/frameworks[other frameworks].

During this exercise you will:

* create an Enonic app
* install and use Content Studio
* get familiar with page components
* Try out page templates
* Use static assets
* and then some...

When you are done, a country page on your site will look something like this:

image::static-assets.png["A rendered country page with the Enonic logo, a text, country facts and a list of cities with an image", width=560px]

[#prerequisites]
== Prerequisites

No prior Enonic experience is required. Basic familiarity with HTML and JavaScript or TypeScript is helpful.

To follow this tutorial you will need:

* A terminal
* Your favorite text or code editor
* https://nodejs.org/[Node.js] with `npm` if you want to install the Enonic CLI via `npm` (other installers are also available)

You will install the Enonic CLI in the first chapter.
